# Eastern European Slav surnames — Pittsburgh/Braddock/South Side 1878.
# Composite corpus: same ethnography as mccoy_slav_given — Polish/Slovak/
# Hungarian/Rusyn/Lithuanian single-man boarding-house labor cohort
# arriving Pittsburgh 1875-1890 for mill and mine work.
#
# Source: Pittsburgh 1878-1885 Thurston's Directory boarding-house
# tenant surnames in South Side wards 24-29 and Braddock borough,
# cross-referenced with ship-manifest Slavic-surname extracts from
# Philadelphia and Baltimore 1875-1880 (primary ports for Pittsburgh-
# bound Slovak/Rusyn labor contracts). Supplemented with Bodnar 1977
# Steelton Slavic surname distributions (direct Pittsburgh-metro comp)
# and with parish marriage-register surnames from St. Stanislaus Kostka
# Polish Strip District (founded 1875), St. John the Baptist Greek
# Catholic (retrospective Pittsburgh Rusyn), and St. Elizabeth Hungarian
# Catholic Braddock (retrospective Magyar 1880s rolls).
#
# Set balance matches given-name set: ~35% Polish, ~25% Slovak, ~20%
# Hungarian, ~15% Rusyn/Ukrainian, ~5% Lithuanian. Female-form
# variants (Kowalska, Nowaková) present where documented. All entries
# attested historical surnames from the cited source streams. No
# invented composites.
