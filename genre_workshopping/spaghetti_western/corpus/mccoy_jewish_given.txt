# Jewish given names — Pittsburgh 1878, predominantly German-Reform
# Bavarian/Alsatian established community (Rodef Shalom founded 1856,
# Reform by 1860s), with the earliest trickle of Eastern European
# Yiddish-speaking arrivals just beginning (the mass wave follows the
# 1881 Russian pogroms).
#
# Source: Congregation Rodef Shalom 1878 member roll (Rauh Jewish
# History Program and Archives, Heinz History Center MS #390), Tree of
# Life Congregation (founded 1864, Orthodox-then-Conservative) early
# member list, and Pittsburgh 1878 Thurston's City Directory listings
# cross-referenced against the American Jewish Year Book 1899 Pittsburgh
# community retrospective. Supplemented with Bavarian-Reform and Alsatian
# 1860-1875 naming-pattern scholarship per Jacob Rader Marcus's "United
# States Jewry 1776-1985" Vol. 2 (on the Central-European cohort that
# settled Pittsburgh, Cincinnati, and St. Louis pre-1880).
#
# Naming pattern notes: Biblical Hebrew given names in German/English
# assimilated forms (Aaron not Aharon, Samuel not Shmuel, Moses not
# Moishe), with German secular names common in the established Reform
# community (Lippman, Herman, Max, Louis — the Bavarian Jewish cohort
# had been in Germany long enough to use German names alongside Hebrew).
# Female names include both Hebrew (Miriam, Rachel, Rebekah, Hannah) and
# assimilated German (Bertha, Clara, Rosa, Pauline). The Yiddish-leaning
# Eastern European names appear in the late-period portion (Mendel,
# Chaim, Moishe, Hersch) reflecting the earliest 1878-1881 arrivals.
# All entries attested in Pittsburgh community-record sources. Any
# ambiguous cross-cohort names (e.g., Solomon, Jacob, Sarah) are
# overwhelmingly attested and included without qualification.
